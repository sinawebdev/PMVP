{# Executive chart primitives — hand-drawn inline SVG, no chart library. Backed by app/analytics.py, which supplies points already carrying `pct` (0-100 of the series peak); these macros only turn that into geometry. Why inline SVG rather than a chart library: both shells must stay fast on Ghanaian mobile data, and the tenant portal is deliberately dependency-free (see the note at the top of portal.css). A library would cost 50-200KB to draw four small cards. Server-rendered SVG costs nothing extra, needs no JS, renders before first paint, prints, and scales to any width. Shared conventions: * A viewBox + `preserveAspectRatio` and width:100% (see .chart in tokens.css) makes every chart responsive with no media queries. * Colour comes from design tokens only (--brand, --accent, --brand-deep). * Each chart is an img-role figure with a text summary for screen readers, and values are also listed in the visible legend/axis, so the data is never SVG-only. * No animation: these are dense executive cards, and a redraw on every dashboard load would be noise. #} {# --- Line chart — a period trend ------------------------------------------ points: [{label, full_label, value, pct}] from analytics. `format` is a Jinja filter name applied to values in the tooltip/summary ('cedis'). #} {% macro line_chart(points, label="Trend", height=132, formatter="cedis") %} {% set w = 320 %} {% set h = height %} {% set pad_x = 6 %} {% set pad_y = 10 %} {% set span = (w - pad_x * 2) %} {% set inner = (h - pad_y * 2) %} {% set step = (span / (points|length - 1)) if points|length > 1 else 0 %} {# y is inverted: pct 100 sits at the top (pad_y), pct 0 at the baseline. #} {% set coords = [] %} {% for p in points %} {% set x = pad_x + (loop.index0 * step) if points|length > 1 else (w / 2) %} {% set y = pad_y + inner - (p.pct / 100 * inner) %} {% set _ = coords.append({"x": x, "y": y, "p": p}) %} {% endfor %} {% endmacro %} {# --- Bar chart — the same periods as magnitude ---------------------------- #} {% macro bar_chart(points, label="By month", height=120) %} {% endmacro %} {# --- Donut — composition of a whole -------------------------------------- mix: {slices: [{label, value, pct, tone}], total} from analytics.cost_mix. Built from stroke-dasharray on concentric circles: one per slice, rotated so slices butt against each other with no path maths. #} {% macro donut(mix, label="Composition", size=150, thickness=18) %} {% set radius = (size / 2) - (thickness / 2) %} {% set circumference = 2 * 3.14159265 * radius %} {% endmacro %} {# --- Sparkline — a trend at table-cell size ------------------------------ Deliberately tiny and label-free: it answers "which way is this going", not "what exactly was March". The precise figures stay in the row's own columns, and the title attribute carries the period values. #} {% macro sparkline(trend, label="cost trend", width=84, height=26) %} {% set points = trend.points %} {% set pad = 3 %} {% set span = width - pad * 2 %} {% set inner = height - pad * 2 %} {% set step = (span / (points|length - 1)) if points|length > 1 else 0 %} {% set coords = [] %} {% for p in points %} {% set x = (pad + loop.index0 * step) if points|length > 1 else (width / 2) %} {% set y = pad + inner - (p.pct / 100 * inner) %} {% set _ = coords.append({"x": x, "y": y}) %} {% endfor %} {% endmacro %} {# --- Delta pill — signed percentage change ------------------------------- change is a signed fraction (0.083 -> +8.3%) or None when there is no baseline. Direction is carried by an arrow glyph AND the wording, never by colour alone. #} {% macro delta(change, suffix="vs previous") %} {% if change is not none %} {{ "▲" if change > 0 else ("▼" if change < 0 else "▬") }} {{ "%+.1f"|format(change * 100) }}% {{ suffix }} {% else %} — {% endif %} {% endmacro %}
